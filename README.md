## Questions & Answers

### 1. What is JSX, and why is it used?
JSX is a syntax extension for JavaScript that looks similar to HTML. It allows React developers to write UI elements in a declarative way. JSX makes code easier to read and helps React understand how to render components.

### 2. What is the difference between State and Props?
- **State**: A local data storage that is mutable and managed within a component.
- **Props**: Read-only values passed from parent to child components.
